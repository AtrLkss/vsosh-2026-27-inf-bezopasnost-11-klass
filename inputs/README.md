# Исходные материалы

Здесь находятся предоставленные в заданиях текстовые файлы, JPEG и PCAP.
Имена приведены к ASCII для удобства запуска скриптов на разных ОС.

| Файл в этой папке | Исходное имя |
|---|---|
| `01-code.cpp` | `1_1011_01_code.cpp` |
| `02-encrypt.py` | `1_1011_02-код.py` |
| `02-ciphertext.txt` | `1_1011_02-текст.txt` |
| `04-photo.jpg` | `1_1011_04_photo.jpg` |
| `07-code.py` | `1_1011_06_code.py` |
| `08-traffic.pcap` | `_1_1011_08_трафик.pcap` |

Исходные материалы заданий принадлежат их авторам. Исполняемые файлы №9 и №10
в репозиторий не включены. Для проверки их нужно скачать из исходного задания
и передать путь к файлу соответствующему скрипту. Скрипты только читают байты EXE.
